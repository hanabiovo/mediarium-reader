# 灵媒 · 信息整合

`mediarium-synthesis` 是一份围绕灵媒 MCP 的阅读技能。MCP 提供文章，skill 告诉模型怎样把材料整理成有脉络的认识：

- **新闻复盘**：整合指定时段内的已读与未读报道，讲清主要事件、关键变化和当前进展。
- **未读导览**：识别近期积压，归纳主线，给出返回信息流的阅读入口。
- **收藏兴趣**：从收藏中建立有文章依据、可以纠正的兴趣档案，帮助发现可能值得读的小事。
- **其他分类**：依内容比较观点、梳理问题或挑选精读文章，不要求所有分类都概括成热点。

## 先接好自己的灵媒

在灵媒「设置 › 接入 AI 助手」生成自己的链接，接入支持 MCP 的客户端。列订阅、搜索文章、读取正文只需要只读链接；无需为这个技能开放管理订阅的权限。详见 [MCP 接入说明](../README.md#接入-ai-助手mcp)。

技能不提供服务账号，也不携带作者的接入链接、订阅清单、文章副本或兴趣档案。每位使用者读取自己的材料。工具前缀可能因客户端而异，技能按实际功能识别，不绑定某个私人服务器或连接别名。

## 在 Codex 中安装

技能源码位于 [`skills/mediarium-synthesis/`](../skills/mediarium-synthesis/)，保留整个目录，包括 `agents` 和 `references`。

可把这段话交给 Codex：

> 从 https://github.com/hanabiovo/mediarium-reader 的 skills/mediarium-synthesis 安装这份技能到我的个人技能目录。先检查同名技能，保留已有内容；使用我自己已连接的灵媒 MCP。

手动安装时，把该目录复制到 `~/.agents/skills/mediarium-synthesis/`。`~` 表示自己的用户主目录；也可让客户端检查其支持的技能位置。若安装后没有出现，重启 Codex。[官方技能说明](https://learn.chatgpt.com/docs/build-skills)

## 通过插件入口安装

本仓库也提供根目录 `plugin.json` 及 `.agents/plugins/marketplace.json`，供支持本地插件市场的桌面环境使用。它只打包技能，灵媒连接仍由使用者自行配置。

使用 Codex CLI 管理插件来源时，可执行：

```sh
codex plugin marketplace add hanabiovo/mediarium-reader
```

然后重启桌面应用，在插件目录中选择“灵媒 · 阅读技能”来源，安装“灵媒 · 信息整合”。直接安装技能和插件安装二选一，避免出现同名副本。[官方插件安装说明](https://developers.openai.com/plugins/build/plugins)

这不会把仓库自动发布到 ChatGPT 公共插件目录，也不代表所有 ChatGPT 网页或手机账号都能直接安装。其他端须使用其支持的技能／插件安装渠道；若仅把规则文件上传给聊天并让它遵循，属于本次使用，不等于长期安装。

## 用起来

安装后可以自然表达需求，也可以显式点名 `$mediarium-synthesis`。技能允许模型自动选择。

> 复盘灵媒过去 48 小时的新闻，包含我读过的内容。告诉我主要发生了什么、进展到哪里，再挑几件值得留意的小事。

> 我几天没看灵媒了，帮我把新闻类别的积压未读理出几条主线，并给出值得细读的入口。

> 检视我的收藏，建立一份有文章依据的兴趣档案。区分明确偏好、暂定观察和单篇线索。

> 按问题和观点整理思想文化类最近一周的文章，挑几篇值得精读的内容，不必做热点榜。

## 兴趣档案与覆盖范围

兴趣档案与技能规则分开。只有用户要求建立或更新时才持久保存，默认位置为 `$CODEX_HOME/skill-data/mediarium-synthesis/interest-profile.md`，未设置 `CODEX_HOME` 时使用 `~/.codex/skill-data/mediarium-synthesis/interest-profile.md`；也可以指定自己的文件位置。无文件持久化能力时，交付可保存的草案，不声称已跨聊天存储。

收藏不等于赞同，未读也不等于没有兴趣。档案应记录文章依据、推断程度及用户更正；普通简报不会自动重写档案。阅读和整合不会代用户标记已读、改变收藏或修改订阅。

截至 2026-11-03 核实的接口，单次文章搜索最多返回 50 篇，没有分页参数。技能会按类别找到订阅源、逐源收集，并报告剩余缺口；不能把局部扫描说成完整覆盖。其他版本以当前实际工具参数为准。

首版已通过技能格式、引用和配置检查，并在作者环境做过小规模只读演练；不同客户端的插件安装和最终成稿效果仍需实际验证。
